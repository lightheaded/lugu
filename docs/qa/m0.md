# M0 manual QA checklist

The M0 exit criterion is "Tom daily-drives it for streaming". These are the checks that
back that claim; they mirror the failure modes lugu exists to fix, so run them against
the real server on a real phone, not an emulator.

## Sign-in and mirror

- [ ] A bare host name (`audiobooks.example`) is accepted without a scheme
- [ ] A wrong password says so, and does not say "cannot reach server"
- [ ] After sign-in the library grid fills; the sync counter shows progress
- [ ] Force-stop the app, turn on airplane mode, reopen: the full library still renders
      and does **not** show the login screen
- [ ] Multiple libraries appear as chips and switching them works

## Playback

- [ ] A book starts within a couple of seconds and the notification appears
- [ ] Position on the player screen matches the notification
- [ ] A multi-file book crosses a file boundary without the position resetting
- [ ] Skip back 10 s three times in quick succession moves back exactly 30 s
- [ ] Podcast episode playback works and is tracked separately from the podcast item

## Position durability (the point of M0)

- [ ] Play for a minute, pause, kill the app from recents, reopen — position kept
- [ ] Play, then `adb shell am kill io.github.lightheaded.lugu` mid-playback, then press
      play on a headset — the right book resumes at the right position with no UI opened
- [ ] **And at the right speed.** Set the book to 1.5x first: the remembered speed used to
      be read only on the path that goes through the app, so a headset press after a kill
      brought a 1.5x book back at 1x. It is applied on the resumption path now, and this is
      the only place that says whether it worked
- [ ] Reboot the phone, press play on a headset — same result
- [ ] Airplane mode: listen for five minutes, pause, wait, re-enable network — the
      server shows the new position within a minute (outbox drained)

## Progress conflicts

- [ ] Move the position forward on another device (web UI), then open the item in lugu:
      lugu adopts the newer position and shows the "moved from another device" banner
- [ ] Tapping **Undo** on that banner returns to the earlier position and the server
      accepts it
- [ ] Listen offline in lugu while the web UI is *behind*; on reconnect the server ends
      up with lugu's newer position, not the stale one

## Housekeeping

- [ ] No crash on rotation on any screen
- [ ] Dark theme and dynamic colour look right
- [ ] TalkBack reads the transport controls and the position slider
